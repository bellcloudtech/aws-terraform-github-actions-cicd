DEPLOYMENT HEALTHY

Automated AWS Cloud Deployment

A secure, containerized application deployed to AWS through an automated CI/CD pipeline built with Terraform, GitHub Actions, Docker, and Amazon ECS Fargate.

01 · INFRASTRUCTURE

Terraform

Reproducible AWS networking, security, load balancing, container orchestration, and monitoring defined as code.

02 · AUTOMATION

GitHub Actions

Automated validation, container builds, secure AWS authentication, and deployment from the main branch.

03 · COMPUTE

ECS Fargate

Serverless container hosting behind an Application Load Balancer with centralized logging in Amazon CloudWatch.

GitHub → GitHub Actions → Amazon ECR → ECS Fargate → Load Balancer
